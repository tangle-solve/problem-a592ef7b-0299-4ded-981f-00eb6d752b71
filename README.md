### ALGO-000029: Graph isomorphism in polynomial time
- **Subfield:** Structural complexity
- **Open:** Give a deterministic polynomial-time algorithm deciding whether two arbitrary finite graphs are isomorphic.
- **Status:** Studied for more than five decades. Babai’s quasipolynomial-time algorithm is a major general breakthrough; polynomial time remains unresolved.
